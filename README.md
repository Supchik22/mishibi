
# Mishibi  
### 🤖 Чат-бот, навчений на ваших Telegram-чатах!

## 📥 Як встановити:

### 🔹Gaming OS ( Windows ):
- Перейдіть до розділу [Releases](https://github.com/Supchik22/mishibi/releases) та завантажте останню версію.
- Розпакуйте
- Відкрийте цю папку
- Створіть тут папку `info` і накидайте туди експортованих `.json` файлів з телеграм.
- Відкрийте `main.exe` 
---

### 🔸 Встановлення з вихідного коду:

1. Клонуйте репозиторій:
   `
   git clone https://github.com/Supchik22/mishibi
   cd mishibi
   `

2. Встановіть залежності:
   `
   pip install -r requirements.txt
   `

3. Створіть файл `.env` у кореневій директорії проєкту (назва файлу може бути будь-яка, але з розширенням `.env`).  
   Додайте в нього ваш ключ API від Groq:
   `
   GROQ_API_KEY=тут_ваш_ключ
   `

   Отримати ключ можна після реєстрації на сайті: [https://console.groq.com/](https://console.groq.com/)
4. Створіть тут папку `info` і накидайте туди експортованих `.json` файлів з телеграм.

5. Запустіть бот:
   `
   python main.py
   `
